# [binwalk-ng](https://github.com/binwalk-ng/binwalk-ng) in a snap #

-------------------------------------------------------------------------------

[![binwalk-ng](https://snapcraft.io/binwalk-ng/badge.svg)](https://snapcraft.io/binwalk-ng)

## Installation ##

[![Get it from the Snap Store](https://snapcraft.io/static/images/badges/en/snap-store-black.svg)](https://snapcraft.io/binwalk-ng)

``` shell
sudo snap install binwalk-ng
```

If you want to analyse files stored on an external USB drive or similar, ensure you manually connect the removable-media interface after installing the snap:

    snap connect binwalk-ng:removable-media

([Don't have snapd installed?](https://snapcraft.io/docs/core/install))
